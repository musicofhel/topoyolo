### Review of PR #1 "Propose SEPARATRIX as seventh machine" (branch `atlas/separatrix`)

**Recommendation: ACCEPT DIRECTIONALLY — merge as PROPOSED seventh machine, with three
gates.** The proposal is unusually well-formed for this repo: it states a falsifiable
signature, documents its own failure cases (EXP-88, F-10), and correctly defers
integration pending annotation.

**Why it clears the "genuine seventh machine" bar:**

1. **Distinct primary object.** METHODOLOGY.md's six machines take cycles/boundaries
   *within* a chain complex, invariants *across* a parameter, assignments between
   features, perturbation bounds, composite-vs-component excess, and destroyed-structure
   nulls. None takes the codimension-1 set *between basins* as the object of study.
   The PR's own "Relation to the Existing Six" section concedes the adjacency honestly
   rather than claiming novelty by fiat — bifurcation sets are separatrices in parameter
   space, but Parameterized Homology tracks invariant change across the sweep;
   SEPARATRIX claims predictive content in the boundary's own measures at fixed
   parameters. Different claim, not rebranding.
2. **Independent rediscovery across ≥3 mutually uncited literatures.** The strongest
   structural evidence: Yang et al.'s boundary thickness and Douven's collated-Voronoi
   thickness problem are the same quantity formulated independently in ML and
   philosophy of language. This is exactly the repetition pattern the Rosetta exists to
   surface (METHODOLOGY.md "The Dual Index").
3. **Built-in falsification criterion.** "μ(∂B) must add predictive power beyond
   distance-to-prototype" plus two measured failures (EXP-88 length-reduction; F-10
   PH-integrates-away-the-signal) means the machine arrives pre-connected to the Null
   Hypothesis machinery. That matches repo ethos better than most existing atlas files.

**Concerns (drive the gates):**

- **G1 — Signature is a family, not one structure.** μ(∂B) ∈ {thickness, barrier
  height, fractal dimension, basin entropy, margin} is five measures. Margin and
  thickness are purely metric (not topological), which strains this repo's charter
  ("cartography of shared *algebraic* structure"). Gate: before promotion from
  PROPOSED, the essay should sharpen the signature — my read is the load-bearing core
  is *boundary-localized discriminative behavior + a scalar boundary measure that beats
  bulk/prototype distance*, and margin should be demoted to the degenerate
  measure-zero case rather than listed as coequal.
- **G2 — Overlap with Stability/Parameterized Homology needs an explicit ANTISYNONYM.**
  Barrier height IS a stability quantity (escape rate); Wada/riddled basins are
  stability-failure objects. The PR gestures at this but doesn't write the
  antisynonym entry. Gate: merging should come with a stub line in
  glossary/ANTISYNONYMS.md separating "robustness of an invariant under perturbation"
  (Stability) from "predictive power of the boundary itself" (SEPARATRIX).
- **G3 — Integration order.** The essay itself says integration follows annotation.
  Enforce it: on merge, SEPARATRIX stays OUT of coverage matrix/glossary/dual index
  until ≥3 of its cited papers survive full B2 annotation. Practical note: accepting
  also means tooling churn — `scripts/gen_stats.py` hardcodes `DOMAINS = [TDA, QEC,
  Dynamics, Neuro, InfoTheo]`, a 6-machine `MATRIX_HEADER`, and MACHINES list; a
  seventh column (and possibly an ML row if Q2 answers "sixth domain") touches A4's
  derived-truth machinery, README stats, and docs/index.html. Do that as a dedicated
  task after G3's annotation threshold, not in the merge commit itself.

**Answers to the PR's three integration questions (my recommendation):**

1. Yes — several cited papers are already adjacent to existing corpus entries (e.g.
   manifold capacity theory connects to existing Statistical Physics/Stability
   annotations); they should be queued for B2 like any other paper, co-instantiating
   machines noted per METHODOLOGY.
2. File ML instantiations under existing domains first (the corpus has precedent:
   STABILITY.md carries an ML section without ML being a domain). Add a sixth domain
   only if a paper fits none — per methodology, that decision is per-paper, deferred
   to B2 triage.
3. One machine with a parameter (∂B dimensionality/thickness), not two. Thin and thick
   boundaries share the signature ∂B = {x : basin(x) not locally constant}; the
   disagreement is about the value of μ(∂B)'s support dimension, which is exactly the
   kind of cross-domain divergence Key Divergences sections exist to record, not a
   machine split.

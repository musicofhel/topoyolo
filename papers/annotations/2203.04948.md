## 2203.04948 — Higgott, Bohdanowicz, Kubica, Flammia & Campbell (2022)
**"Improved decoding of circuit noise and fragile boundaries of tailored surface codes"**

**Domain(s)**: Quantum error correction

**Abstract machines instantiated**:
- **Matching**: The decoding core remains MWPM; the contribution is what feeds it. Belief-matching runs belief propagation on the full circuit-level noise model and hands BP posteriors to the matching decoder as reweighted edge costs — a two-stage composition of message passing with matching, in direct lineage of the Mézard–Mora "BP = soft matching on factor graphs" identification already in the corpus.
- **Chain complex**: Circuit-level noise model as a factor graph / syndrome lattice over spacetime (the same 2+1D structure the Floquet-code entry uses); BP operates on this graph, matching operates on its defect pairs.
- **Phase transitions**: Threshold moved from 0.82% (plain MWPM) to 0.94% under circuit-level depolarising noise — the critical error rate as the performance metric, shifted by decoder-side information use.
- **Stability**: The "fragile boundaries" phenomenon is a stability finding of an unusual sign: well below threshold, the rectangular (untailored) surface code overtakes the boundary-tailored code in resource efficiency — a resource-optimal configuration that *reverses* across parameter space, driven by boundary sensitivity.

**What is genuinely new (not reducible to shared abstraction)**:
- Belief-matching/belief-find themselves: the specific composition where BP handles correlated circuit-level noise and matching handles the resulting marginal problem — neither stage alone achieves the threshold, and the interface (BP posteriors as edge-weight updates) is the contribution.
- Fragile boundaries: previously unnoticed phenomenon where tailored boundaries that raise threshold near it become a liability deep below threshold. Boundary geometry's effect on code resources flips sign with noise regime — no abstract-machine template predicts the reversal.
- The case-study methodology: decoders evaluated jointly with code tailoring, showing decoder and code-family choices are not separable optimizations.

**Connections the authors acknowledge**: Surface-code QEC experimental program; standard MWPM; belief propagation lineage; tailored/biased-noise codes (XZZX-style). Abstract-only provenance — depth-limited.

## 2303.16716 — Grande & Schaub (2023)
**"Topological Point Cloud Clustering"**

**Domain(s)**: TDA

**Abstract machines instantiated**:
- **Chain complex**: The core object is a simplicial complex constructed from the point cloud (via k-nearest-neighbor graphs and closed neighborhoods), whose algebraic representation is the set of Hodge Laplacians L_k = B_{k+1} B_{k+1}^T + B_k^T B_k built from incidence (boundary) matrices. Where classical spectral clustering uses only L_0 of the pairwise graph, TPCC runs sparse eigenvector computations on the whole family {L_k}, i.e. it reads structure off every level of the chain complex rather than the 0-skeleton alone.
- **Matching**: The final clustering step assigns each point to the topological feature (connected component / cycle / cavity) it contributes to — an assignment of data points to global structures, replacing spectral clustering's assignment-to-eigenvector-sign with assignment-to-homology-basis-element. Points in the "boundary region" between features get soft assignments via multiple eigenvectors.
- **Stability**: The paper leans on the relative robustness of topological techniques against noise: because cluster identity is tied to global homology rather than to local metric detail, perturbations that jitter points but preserve the underlying complex's topological features do not change the clustering. Interpretability claim parallels spectral clustering's (sparse eigenvectors), but the invariant being preserved is topological.

**What is genuinely new (not reducible to shared abstraction)**:
- The pipeline direction is inverted relative to most TDA: instead of computing persistent homology *of* the point cloud as a summary, TPCC pushes homological structure back *down* to individual points — each point receives a label saying which cycle/cavity/component it participates in. This point-level attribution of homological contributions is not one of the six machines.
- It deliberately avoids the persistence/filtration machinery entirely: no barcode, no parameter sweep. Structure is read from a single complex at fixed scale, using only sparse extremal eigenvectors of Hodge Laplacians. A TDA method with no parameterized homology.
- The practical bridge to graph-based ML: TPCC is positioned as a drop-in interpretability layer over spectral clustering pipelines, which makes the chain-complex view consumable by standard unsupervised learning without new theory.

**Connections the authors acknowledge**: Explicitly builds on spectral clustering (von Luxburg) and on Hodge-Laplacian signal processing on simplicial complexes (Schaub et al., Barbarossa et al.). No connections drawn to QEC, information theory, dynamical systems, or neuroscience; no persistent homology literature engaged beyond positioning against it.

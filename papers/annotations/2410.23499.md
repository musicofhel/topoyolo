## 2410.23499 --- Butler, Waxman & Djurić (2024)
**"Tangent Space Causal Inference: Leveraging Vector Fields for Causal Discovery in Dynamical Systems"**
arXiv: 2410.23499 | cs.LG, nlin.CD

**Domain(s)**: Dynamical systems, machine learning

**Abstract machines instantiated**:
- **Matching**: CCM's cross mapping is nearest-neighbor matching between reconstructed state spaces; TSCI replaces it with explicit local linear fits — learned vector fields on the reconstructed manifolds — and tests the *degree of synchronization* between the fitted fields. The matching is moved from neighbor retrieval to function approximation on tangent spaces.
- **Null hypothesis**: The method's claim against CCM inherits the null-surrogate logic: CCM fires spuriously when data quality degrades (noise, short series); TSCI's basic version is claimed more accurate at comparable cost, i.e. a lower wrong-alternative rate on standard benchmark systems — an empirical calibration of the synchronization-based causal test.
- **Joint-vs-marginal excess**: Synchronization between two systems' learned vector fields is precisely structure present in the coupled composite that neither series alone exhibits; causality detection = detecting that excess.

**What is genuinely new (not reducible to shared abstraction)**:
- Replacing the implicit representation (delay-embedding library + neighbor matching) with an explicit dynamical object: the vector field itself is estimated, then compared field-to-field. The causal signal migrates from "can states be predicted across manifolds" to "do the local linear dynamics agree" — a shift from state-space geometry to tangent-bundle geometry that no other corpus CCM-variant entry makes.
- Model-agnostic ladder: basic local-linear version up through latent-variable/deep-learning-augmented versions of the same synchronization test, all drop-in for CCM — the test statistic stays fixed while the function class grows.

**Connections the authors acknowledge**: CCM (Sugihara et al.) and its generalizations as the direct baseline; Granger causality as the regime where it fails. No Rosetta-cross-domain awareness.
